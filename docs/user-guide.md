## 保险库与记录管理

- 首次启动创建本地保险库，或填写云服务配置并输入已有主密码连接云端保险库，也可以导入加密备份。
- 表用于分类，Key 在同一张表内唯一且区分大小写。Value 与备注均支持多行纯文本；搜索包含三者。
- 编辑后点击保存，或按 `Ctrl/Cmd+S`。切换记录、表、设置、退出应用或手动锁定时，会提示处理未保存内容；最小化到托盘保留草稿。
- 已有记录的 Value 默认隐藏，列表中的「显示值」开关可一键切换列表和当前编辑区，并在锁定后重置。新建记录的 Value 直接可编辑。列表支持独立复制 Key、Value，隐藏状态下也可以直接复制；剪贴板内容不会自动清空。
- 列表使用 58px 紧凑行高；点击记录正文打开详情，点击左侧图标勾选或取消，连续点击图标即可多选，无需按住修饰键。`Shift` 点击图标按当前排序选择连续范围，`Ctrl/Cmd+Shift` 点击追加范围。勾选与查看详情相互独立，保留当前草稿；右键支持编辑、复制、移动到数据表和删除，右键已选记录保留多选，右键未选记录改为单选。
- 多选后可通过右键菜单或工具栏批量移动、删除；列表聚焦时 `Ctrl/Cmd+A` 全选当前筛选结果，`Esc` 取消选择，`Delete` 打开删除确认。更改搜索、切换表或锁定时清理选择；同步删除或移动后剔除不再可见的选择。批量操作一次性加密保存，移动遇到目标表或所选记录之间的重复 Key 时整批取消，不覆盖记录；删除保留同步墓碑。
- 点击列表工具栏的「编辑」进入排序模式，用左侧手柄拖动项目，再点击「保存排序」一次性加密保存。手柄支持空格启动、方向键移动、回车确认的键盘操作；「取消排序」恢复已保存顺序。编辑排序时暂时禁用搜索和记录编辑，需先清除搜索；离开或关闭窗口会提示处理未保存的排序，也可按 `Ctrl/Cmd+S` 保存。排序按钮在自定义、Key 和更新时间三种视图间切换，默认使用已保存的自定义顺序。
- 默认无操作 5 分钟后自动锁定。在“设置 → 通用”中可关闭自动锁定，或指定 1–1440 分钟的闲置时长，点击“保存设置”后生效；设置保存在本机明文配置文件，重启后保留，不随云同步发送到其他设备。自动锁定会丢弃尚未显式保存的编辑。`Ctrl/Cmd+K` 搜索，`Ctrl/Cmd+Shift+L` 锁定。
- 外观可选择浅色、深色或跟随系统，偏好由 Rust 保存到本机 `config.json`。

## 托盘与关闭行为

启动时自动创建托盘图标。点击图标或托盘菜单「打开 KVault」恢复窗口；Linux 通过托盘菜单打开。macOS 使用自动适配菜单栏颜色的单色图标。

默认点击窗口关闭按钮时询问「退出应用」或「最小化到托盘」。最小化会隐藏窗口，保留未保存草稿，继续同步和自动锁定计时。退出时仍需处理未保存的编辑或排序，退出后清理解锁会话。

“设置 → 通用 → 窗口关闭行为”提供「关闭时最小化到托盘」和「关闭时再次询问」两个开关，更改后立即保存到本机配置。关闭询问后，关闭按钮直接采用设定的行为；也可以在关闭弹窗中关闭「下次关闭时仍然询问」，记住本次选择。托盘菜单「退出 KVault」和系统退出命令始终请求退出，不受最小化设置影响。

## 批量导入

点击右上角「批量导入」，选择 UTF-8 CSV 文件，或直接粘贴纯文本。先预览，选择目标数据表和重复 Key 策略，再确认导入。每行依次为 Key、Value、可选备注；支持自动识别 `key,value,notes`（或「键、值、备注」）表头，也可手动指定有无表头。

空格 / Tab 分隔的纯文本示例：

```text
api.token abc123 生产环境
username alice
description "value with spaces" "包含空格的备注"
```

逗号分隔的纯文本或 CSV 示例：

```csv
key,value,notes
api.token,abc123,生产环境
description,"value, with comma",备注
```

同一批次使用相同分隔符，含分隔符的字段使用双引号，字段内双引号写成 `""`；CSV 也支持带引号的多行 Value。默认跳过重复 Key，选择覆盖时会替换 Value 和备注，保留已有记录的 ID 与创建时间；批内重复也遵循相同策略，覆盖时最后一行生效。

无效行会显示行号，默认阻止导入；可明确选择跳过无效行后导入其他记录。一次最多 10000 行、10 MiB，预览最多显示前 100 行。整批导入只执行一次加密写入，失败时保留原保险库；成功后按正常规则自动同步。粘贴内容、CSV 原文和预览仅保留在当前弹窗内存中。

## 云同步

设置窗口左侧选择“通用、云同步、安全与备份”分类，右侧显示对应选项。点击左下角的云存储入口，直接进入“云同步”分类。每次只启用一个目标：

- **S3 兼容存储**：填写服务地址、Region、Bucket、Access Key ID、Secret Access Key，以及按需使用的 Session Token、路径前缀和 Path Style。
- **WebDAV**：填写服务地址、目录、用户名和密码。

先测试连接，再保存并启用。目标服务需要支持 ETag 条件写入；测试不通过时不会启用写同步。连接测试会创建并清理临时探针对象，需要相应读写、删除权限；WebDAV 新目录还需要创建目录权限。

首次连接已有云端保险库时，需要在首次启动界面配置目标并输入该保险库的主密码。已有本地保险库可在设置中连接空目标并初始化；不同保险库 UUID 的数据不能自动合并或覆盖。

保存先写本地，随后安排同步。同步期间可以继续编辑；离线修改保留在本机，网络恢复后重试。界面会显示待同步、同步中、已同步、离线、失败或冲突等状态。

遇到冲突时，打开冲突处理界面，选择采用本地、采用云端或保留双方。保留双方需要满足表名、表内 Key 唯一的约束。未解决的冲突会保留在本机，暂停上传和常规编辑。

## 主密码与自动锁定

- 主密码至少 8 个字符，用同一主密码解锁整个保险库。
- 已启用同步时，修改密码需要联网，先完成同步并处理冲突。
- 云端上传结果无法确认时，应用会进入只读恢复状态。保留本地文件，联网后按提示恢复。
- 其他设备先用旧密码解锁本地保险库，再在设置中输入新密码迁移；旧密码下的离线修改会参与合并。
- 手动锁定前可保存或放弃当前修改；自动锁定会丢弃尚未保存的内容，包括临时排序。
- 锁定页从本机配置读取实际闲置分钟数，或显示“自动锁定已关闭”，刚启动时也可显示，无需先解密保险库。

## 加密备份

在“设置 → 安全与备份”中导出或导入 `.kvault` 加密快照。

导入备份会替换本地数据、清除同步配置，并撤销旧的系统解锁授权；本机主题和自动锁定设置保留，操作前建议先导出当前保险库。历史备份继续使用生成时的密码，之后修改主密码不会改变这些备份。

备份文件应另存到可靠位置；本地自动保留的上一版本文件用于写入恢复，不能替代独立备份。底层文件与恢复规则见[技术报告](technical-report.md#本地持久化与备份)。

## 快捷键

| 操作                           | 快捷键                                           |
| ------------------------------ | ------------------------------------------------ |
| 保存记录或当前排序             | Ctrl / Cmd + S                                   |
| 聚焦搜索                       | Ctrl / Cmd + K                                   |
| 锁定保险库                     | Ctrl / Cmd + Shift + L                           |
| 全选当前筛选结果（列表聚焦时） | Ctrl / Cmd + A                                   |
| 取消勾选（列表聚焦时）         | Esc                                              |
| 打开删除确认（列表聚焦时）     | Delete                                           |
| 连续范围勾选                   | Shift + 点击左侧图标                             |
| 追加范围勾选                   | Ctrl / Cmd + Shift + 点击左侧图标                |
| 键盘拖动排序手柄               | 空格启动、方向键移动、回车确认、Esc 取消当前拖动 |

macOS 使用 Cmd；Windows、Linux 使用 Ctrl。排序模式中的 Esc 用于取消当前拖动，退出整个排序模式请点击“取消排序”。

## 可选系统解锁

“设置 → 安全与备份 → 系统解锁”默认关闭。启用时确认当前主密码，再按系统提示完成验证；之后锁定页多出一个系统解锁按钮，主密码入口始终保留。取消验证、设备不可用或授权失效时，都可以改用主密码。

- macOS 使用 Secure Enclave 与 Touch ID 或系统允许的本机验证，需要 macOS 11+ 及支持的硬件。
- Windows 使用 Windows Hello PIN、指纹或面容，需要先在系统设置中配置 Hello；设备必须支持所需的密钥保护策略。
- Linux 当前使用主密码解锁，云凭据仍保存在 Secret Service。

关闭开关或修改主密码会清除本机授权。系统解锁配置不会上传；其他设备需要分别启用，且不能替代主密码备份。外观与自动锁定以明文保存，云配置保存在系统凭据库，记录全部加密为二进制文件，详见 [存储说明](storage-security.md)。

本次为全新 v2 格式，不直接读取旧版 v1 保险库或加密备份。为新保险库使用空的云端目录/前缀；原有云文件不会被自动覆盖。
